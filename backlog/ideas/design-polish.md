## Problem
The HTML report is the only thing anyone will look at, and a rich, pretty
report is an explicit goal, not a finishing touch. A retro that people
read every Monday deserves the reading experience of a good newsletter,
not a grid of cards. This is one HTML template, its chart styles, and a
print stylesheet for the PDF.

## Proposal
Design the template alongside the first real report, not after it, using
the design engineering skills installed in `.agents/skills/` (reviewed
2026-09-02). Typography and spacing first; chart styling consistent with
the text; motion only for the optional interactive layer and never
required to read the page. Check it in light, dark, and print.
